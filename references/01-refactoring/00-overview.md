# Refactoring

[![Refactoring](https://refactoring.guru/images/refactoring/content/index/refactoring-i1.png?id=4ba85db5ddb3da0cd829bc7c0d2bf407)](https://refactoring.guru/refactoring/what-is-refactoring "Intro to refactoring")

Refactoring is a systematic process of improving code
without creating new functionality that can transform
a mess into clean code and simple design.

[Start from the very beginning](https://refactoring.guru/refactoring/what-is-refactoring)

### Dirty Code

[![Dirty Code](https://refactoring.guru/images/refactoring/content/index/refactoring-i2.png?id=dbf9c791a67f14d41250603d0bcec6fd)](https://refactoring.guru/refactoring/technical-debt "Dirty Code")

Dirty code is result of inexperience
multiplied by tight deadlines,
mismanagement, and nasty
shortcuts taken during the
development process.

[Learn more](https://refactoring.guru/refactoring/technical-debt)

### Clean Code

[![Clean Code](https://refactoring.guru/images/refactoring/content/index/refactoring-i3.png?id=e393546f4f2d0046fdbf98b75c6c35ea)](https://refactoring.guru/refactoring/what-is-refactoring "Clean Code")

Clean code is code that is easy to read,
understand and maintain. Clean code makes
software development predictable
and increases the quality
of a resulting product.

[Learn more](https://refactoring.guru/refactoring/what-is-refactoring)

### Refactoring Process

[![Refactoring Process](https://refactoring.guru/images/refactoring/content/index/refactoring-i4.png?id=e4ba322684937f8c166dfd8f2d6ecfb1)](https://refactoring.guru/refactoring/how-to "Refactoring Process")

Performing refactoring step-by-step and
running tests after each change are key
elements of refactoring that make it
predictable and safe.

[Learn more](https://refactoring.guru/refactoring/how-to)

### Code Smells

[![Code Smells](https://refactoring.guru/images/refactoring/content/index/refactoring-i5.png?id=acb5ca2349f078fa48ea57b5ad1ee0f5)](https://refactoring.guru/refactoring/smells "Code Smells")

Code smells are indicators of problems that can be
addressed during refactoring. Code smells are
easy to spot and fix, but they may be just
symptoms of a deeper problem
with code.

[Learn more](https://refactoring.guru/refactoring/smells)

### Refactoring Techniques

[![Refactoring Techniques](https://refactoring.guru/images/refactoring/content/index/refactoring-i6.png?id=7f2e9d6b728193f982cfc4d2dbd384d0)](https://refactoring.guru/refactoring/techniques "Refactoring Techniques")

Refactoring techniques describe actual refactoring
steps. Most refactoring techniques have their
pros and cons. Therefore, each refactoring
should be properly motivated and
applied with caution.

[Learn more](https://refactoring.guru/refactoring/techniques)
